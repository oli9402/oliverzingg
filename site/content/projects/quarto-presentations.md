In quarto for R environment we can create presentations that runs on revealjs. The rendered quarto file results in a HTML file that can be open in regular browsers and makes it great for sharing. Using scss the presentation can be customized. Using R packages like echarts4r we can use javascript tools for creating interactive plots. Compared to a dashboard this can be helpful to guide an audience through specific plots in a presentation style which can be easier to follow or communicate a certain message.

As an example here is a very simple presentation created: [Link to fullscreen presentation](https://oli9402.github.io/Interactive-Slides-)

Using *iframes* we can incorporate the same presentation into this blog post but certain controls like **F for fullscreen** doesn’t work.
