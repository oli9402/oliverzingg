<section id="introduction" class="level1">

<p>Real world data is often naturally or ideally structured as graphs. Especially, relational data is modeled better with graph compared to tabular form. GNN extends machine learning model to use graph data format as input. The idea is to learn embeddings of feature vectors that caputres infos about individuals nodes but also how nodes are connected. This leads to richer and more comprehensive understanding of the data. GNN is just UPDATE and AGGREGATE functions</p>
</section>

<p>With ML we can pad images (or center crop) or sequences to have same sized input. With graphs it’s a bit different. They have highly irregular structure.</p>

<section id="permutation-invariance" class="level2">
<h3 class="anchored" data-anchor-id="permutation-invariance">Permutation invariance</h3>
<p>Traditional data formats = structure of data is fixed and meaningful. With graph there is a lack of natural order and this is refered to as <em>permutation invariance</em></p>
<p>Embeddings are compact summary of local grpah structure. Thus connected nodes must have similar embeddings.</p>
<p>Graph convolution networks are most wiedely applied arichtecture.</p>
</section>
<section id="gcn-gnn" class="level2">
<h3 class="anchored" data-anchor-id="gcn-gnn">GCN /GNN</h3>
<ul>
<li>Key idea generate representation of a node that depends on the structure of the graph + any feature information of that node</li>
<li>CNN aggregates features information from spatially defined patches in an image using convolution operations.</li>
<li>GCN are similar as they aggregate information based on local graph neighborhoods. The idea is that neighboring nodes have information about a node. Aggregating neigbhoors and node gives enhanced features. This agg needs to be normalized since nodes can have drastic different numbers of neighbors and would bias training.</li>
<li>In traditional data formats like images and text, the order or structure of the data is fixed and meaningful.</li>
<li>Changing the order of words will change the meaning of the sentence and modeling results.</li>
<li>In a graph, nodes (representing entities) are connected by edges (representing relationships), and there is no inherent ordering of these nodes. This lack of a natural order leads to the necessary property of the function to be permutation invariant.</li>
</ul>
<p>Why not feed each row of concat(adjacency matrix, feature matrix)?:</p>
<ul>
<li>it would depend on the arbitrary ordering of nodes that we use in the adjacency matrix</li>
<li>such a model is not permutation invariant. But it must be permutation invariant.</li>
<li>Thus, when working with graph data, the model should produce the same output regardless of the order in which the nodes and their neighbors are presented.</li>
<li>The model must treat these permutations of the input as equivalent.</li>
<li>Translating nodes (e.g.&nbsp;neighbors) into a vector we have to enforce arbitrary ordering of these nodes. This would produces different outputs in a ML like CNN.</li>
<li><strong>DEFINING FEATURE OF GNN IS THAT IT USES A FORM OF NEURAL MESSAGE PASSING</strong></li>
</ul>

<p>How does a node in layer 2 get information from 2 hops?</p>
<ul>
<li>By aggregating again its neighbors it receives information from 2 hop because neighbors have aggregated information from their neighbors in layer 1 and this is passed to the node in layer 2.</li>
<li>k iteration = k hops away</li>
</ul>
<p><strong>Major issue with GCN = over-smoothing</strong></p>
<ul>
<li>with 10+ layers all nodes start to look the same because they keep averaging over larger neighborhoods</li>
</ul>
<p>In GCN layer the two weight matrices are shared for all nodes (parameter matricies: W and B):</p>
<ul>
<li>this helps with generalization to unseen nodes</li>
<li>helps with computation</li>
<li>model output does not depend on node ordering: GCN is permutation invariant</li>
<li>a function how to aggregate is learned nothing really tied to a single node</li>
<li>message passing = local feature-aggregation behaviour (like CNN- convolutional kernels)</li>
</ul>

<section id="structural-causal-model-scm---m" class="level3">
<h4 class="anchored" data-anchor-id="structural-causal-model-scm---m">Structural causal model (SCM) - M</h4>
<ul>
<li>a way of describing relevant features of the world and how they interact with each other</li>
<li><strong>edogenous</strong>: variables determined within the causal system
<ul>
<li>part of causal mechanism</li>
<li>influenced by other variables in the model</li>
<li>is correlated with unobserved factors that affect outcome</li>
<li>e.g.&nbsp;education/income</li>
<li>caused by at least one exogenous variable</li>
</ul></li>
<li><strong>exogenous</strong>: variables that determined outside the causal system being modeled
<ul>
<li>i.e.&nbsp;<em>not caused by any variable inside the model</em></li>
<li><em>not affected by other variables in the model</em></li>
<li>often treated as independent inputs</li>
<li>help identify causal effects because they provide variation that is not influenced by the outcome</li>
<li>e.g.: completley randomly assigned scholarships</li>
</ul></li>
</ul>
<p><strong>SCM consists of</strong>:</p>
<ol type="1">
<li>U: set of exogenous variables</li>
<li>V: set of endogenous variables</li>
<li>F: set of functions that assign each variable in V a value based on the values of the other variables in the model</li>
</ol>

<section id="graphical-causal-models" class="level3">
<h4 class="anchored" data-anchor-id="graphical-causal-models">Graphical Causal Models</h4>
<p>Every SCM is assocaited with a graphical causal model, and consists of:</p>
<ol type="1">
<li>set of nodes representing variables in U and V</li>
<li>set of edges representing the functions in f</li>
</ol>
<ul>
<li>edges can be directed vs.&nbsp;undirected
<ul>
<li>starting node = <strong>parent</strong></li>
<li>end node = <strong>child</strong></li>
<li>for multiple connection: starting point == <strong>ancestor</strong> and every node on the path is <strong>descendant</strong></li>
</ul></li>
<li>Consequently, every endogenous variable in a model is a <strong>descendant</strong> of at least one exogenous variable</li>
<li>exogenous variables cannot be descendants of any other variables (root nodes in a graph).</li>
</ul>
<p>Graphical definition of causation:</p>
<blockquote class="blockquote">
<p>if in graphical model: X is child of Y then Y is direct cause of X. If x is desendant of Y, then Y is potential cause of X. ### DAG: Directed Acyclic Graphs (Bayesian networks)</p>

<section id="frontdoor-criterion" class="level2">
<h3 class="anchored" data-anchor-id="frontdoor-criterion">Frontdoor Criterion</h3>
<p>If there is a mediator M that lies on all causal paths from X to Y, and there are no unblocked backdoor paths from X to M or from M to Y, then the causal effect of X on Y can be identified using the front-door adjustment formula.</p>

<h3 class="anchored" data-anchor-id="simpsons-paradox">Simpsons Paradox</h3>
<p>Appears when a confounder affects both treatment assignment and outcome. A randomly selected subgroup of the population can show a different relationship between treatment and outcome than the overall population, leading to a paradoxical reversal of the observed effect when data is aggregated. If we randomly selected a patenint in treatment its most likely a women and women have less baseline recovery rate (generally less recovery due tue e.g.&nbsp;estrogen)</p>
